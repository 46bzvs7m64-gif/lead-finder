# 客户线索自动收集与打分工具

ToB 销售的线索清洗与优先级排序工具：多渠道原始线索汇入后，自动完成号码标准化、去重、条件筛选和打分排序，把"翻名单找客户"变成"按分数打电话"。

## 功能

1. 读取多渠道线索表（企业名录 / 展会名片 / 平台导出，表头一致即可）
2. 手机号 / 座机标准化提取，按号码去重（同号不同格式只保留信息最全的一条）
3. 按城市、行业关键词筛选
4. 线索评分（满分 100）：联系方式完整度 + 决策人线索 + 来源质量 + 需求关键词
5. 导出排序 CSV，控制台输出收集漏斗（原始→去重→有效号码→筛选后）

## 使用（Python 3，零依赖）

```bash
python lead_finder.py --city 成都 --industry 广告
python lead_finder.py                       # 处理全部
```

不想本地运行也可以直接看 [`demo_output.txt`](demo_output.txt)（全量运行的控制台输出）和 [`leads_ranked.csv`](leads_ranked.csv)（打分排序后的导出结果）。

## 数据说明

`demo_sources.csv` 为 24 条演示线索（含重复号码、座机、无号码脏数据）。`lead_finder.py` 末尾的 `fetch_page()` 演示了如何接公开网页数据源：遵守目标网站 robots 与使用条款，仅采集企业公开发布的商务联系方式。

## 面试可讲

- 销售漏斗最上游是线索质量，先去重再外呼，避免同一个客户被重复骚扰
- 评分模型的业务逻辑：决策人直联 > 总机、转介绍 > 冷名录、带需求信号 > 无备注
